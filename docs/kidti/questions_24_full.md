## 附录：计分规则说明

### 维度映射

| 维度代码 | 全称 | 正向极 | 负向极 |
|---------|------|-------|-------|
| D1 | 能量源 NRG | BATTERY (电池-独处充能) | REACTOR (反应堆-社交充能) |
| D2 | 规则观 RUL | SHEEP (绵羊-守规矩) | WOLF (狼-挑战权威) |
| D3 | 存在感 PRE | BLACKHOLE (黑洞-回避关注) | SPOTLIGHT (聚光灯-渴望关注) |
| D4 | 情绪天气 EMO | CLEAR (晴朗-情绪可预测) | FOG (雾-情绪矛盾不可预测) |

### FOG判定逻辑（D4特殊机制）

在6道D4题目中，如果受试者同时满足以下模式，则判定为FOG：
- 至少2题选了A（极端情绪爆发）
- 同时至少2题选了B（情绪麻木/抽离）

这表明受试者的情绪反应模式存在**极端矛盾**——同一人在不同情境中可能在"情绪爆炸"和"情绪死寂"之间无规律切换，令他人完全无法预测其情绪走向。

### 偏移值规则

| 偏移值 | 含义 |
|-------|------|
| +2 | 强正向——该维度下非常典型的表现 |
| +1 | 弱正向——轻微倾向 |
| -1 | 弱负向——轻微反向倾向 |
| -2 | 强负向——该维度下极端反向表现 |

### 最终人格计算

1. 每个维度独立计算总分（所有题目偏移值累加）
2. D1总分 > 0 → BATTERY，< 0 → REACTOR
3. D2总分 > 0 → SHEEP，< 0 → WOLF
4. D3总分 > 0 → BLACKHOLE，< 0 → SPOTLIGHT
5. D4总分 > 0 → CLEAR，< 0 → FOG（需满足FOG特殊判定条件）
6. 四个维度组合映射到24种人格类型之一
