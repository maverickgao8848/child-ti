## 1. 项目概述

### 1.1 核心定位

儿童TI 是一款**纯前端单页人格测试应用**。用户回答 24 道童年情境选择题，系统根据 4 维度计分模型匹配出 1 种"童年人格"，生成带分享卡片的结果页。

> **不是儿童心理学测评，而是一份"童年创伤回忆录"**——用成年人的视角，笑着说出小时候那些其实挺惨的真相。

### 1.2 北极星行动

用户完成测试后，**分享结果页到微信/朋友圈**。

### 1.3 成功指标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 完成率 | ≥ 70% | Cloudflare Web Analytics |
| 分享率 | ≥ 15% | 分享按钮点击事件 + 链接复制事件 |
| 微信兼容性 | 100% | iOS/Android 微信内置浏览器手动测试 |
| 首屏加载 | < 1s | Lighthouse / WebPageTest |

### 1.4 目标用户

- **年龄**：18-35 岁
- **身份**：互联网原住民，活跃于微信/微博/小红书
- **心理特征**：对童年有复杂情感（怀旧 + 自嘲 + 轻微创伤），习惯用"自黑"进行社交表达
- **使用场景**：微信群闲聊时点击链接、朋友圈看到好友分享后好奇测试、微博/小红书话题参与

### 1.5 核心策略

**零门槛、快传播**：
- 无需注册/登录
- 24 题 3-5 分钟完成
- 结果即出即分享
- 单文件部署，任何网络环境秒开

## 3. 用户路径流向

### 3.1 主路径：首次访问 → 完成 → 分享

```
用户点击链接/扫码
    ↓
首页（Start Page）
├── 品牌标题："儿童 TI"
├── 副标题："你是什么儿童？"
├── 核心信息："24 道题，测出你的童年人格"
├── CTA："开始测试"按钮
└── 底部："纯属娱乐 · 无心理学背书"
    ↓ 点击"开始测试"
答题页（Quiz Page）
├── 弱化品牌标题
├── 进度："第 N 题 / 共 24 题" + 进度条
├── 题目文本区
├── 4 个单选选项（A/B/C/D）
└── "上一题"按钮（第 1 题隐藏）
    ↓ 选中最后一题选项
结果页（Result Page）
├── 品牌标题
├── 人格配图（正方形，视觉中心）
├── 人格代号（大字号，如"KPBL"）
├── 中文名（如"我没事型"）
├── 一句话定义
├── 详细解读文本（2-3 段）
├── 黑色幽默 Slogan（引用式展示）
├── 维度解读区：4 条进度条 + 维度标签
├── 操作区："分享给朋友"、"重新测试"
└── 二维码区：当前页面二维码 + "扫码测测你是什么儿童"
    ↓ 点击"分享给朋友"
分享海报（Canvas 浮层）
├── 顶部：品牌名 "儿童TI"
├── 中间：人格配图（缩小版）
├── 人格代号 + 中文名
├── 一句话定义
├── Slogan（精选一句）
└── 底部：二维码 + "扫码测测你是什么儿童"
    ↓ 保存/分享图片
用户分享到微信/朋友圈
```

| 模块 | 内容元件 | 数据要求 |
|---|---|---|
| **品牌弱化区** | 小号品牌标题 | "儿童 TI"，弱化显示 |

- 第 24 题选中后 → 自动跳转结果页
- 返回上一题修改后，新选择覆盖旧选择，重新累加计分

**校验规则**：
- 每题必须且只能选 1 个选项

|---|---|---|
| **品牌区** | 品牌标题 | "儿童 TI" |

## 5. 状态与数据流

### 5.1 内存状态对象

```javascript
const state = {
  currentQuestion: 0,      // 当前题号 0-23
  answers: [],             // 每题选中的选项索引 [0, 2, 1, ...]
  scores: { NRG: 0, RUL: 0, PRE: 0, EMO: 0 },  // 四维度累积分
  personaCode: null,       // 最终匹配的人格代号
};
```

### 5.2 运行流程

1. **初始化**：解析 URL 参数 → `?code=KPBL` 直接渲染结果页；无参数 → 显示首页
2. **开始测试**：首页点击"开始测试" → 重置分数数组 → 显示答题页 → 渲染第 1 题
3. **答题过程**：选中选项 → 记录答案 + 累加计分 → 自动渲染下一题；最后一题 → 计算人格 → 渲染结果页
4. **分享**：结果页点击"分享给朋友" → Canvas 合成海报 → 生成 Blob → 触发下载
5. **重测**：结果页点击"重新测试" → 清空状态 → 回到首页

## 7. 人格体系速查

### 7.1 四维度定义

| 维度 | 代号 | 极A | 极B | 判定规则 |
|---|---|---|---|---|
| D1 能量源 | `NRG` | **BATTERY**（充电型） | **REACTOR**（放电型） | 总分高 = BATTERY，低 = REACTOR |
| D2 规则观 | `RUL` | **SHEEP**（顺毛型） | **WOLF**（反骨型） | 总分高 = SHEEP，低 = WOLF |
| D3 存在感 | `PRE` | **BLACKHOLE**（黑洞型） | **SPOTLIGHT**（聚光型） | 总分高 = BLACKHOLE，低 = SPOTLIGHT |
| D4 情绪天气 | `EMO` | **STORM**（暴雨型） | **LAKE**（静海型） | **FOG**（迷雾型） | 特殊矛盾检测法 |

### 7.2 24 人格映射表

| D1+D2 | D3=BLACKHOLE, D4=STORM | D3=BLACKHOLE, D4=LAKE | D3=BLACKHOLE, D4=FOG | D3=SPOTLIGHT, D4=STORM | D3=SPOTLIGHT, D4=LAKE | D3=SPOTLIGHT, D4=FOG |
|---|---|---|---|---|---|---|
| BATTERY + SHEEP | **KPBL** | **WALL** | **IMOK** | **KPI** | **DAREN** | **CTRLC** |
| BATTERY + WOLF | **NUKE** | **DAMN** | **NEIG** | **TNT** | **STUDY** | **GODD** |
| REACTOR + SHEEP | **GLUE** | **502ER** | **RUOK?** | **JOKER** | **MAPI** | **TRUMP** |
| REACTOR + WOLF | **CHAOS** | **STEAM** | **IPHONE** | **BOSS** | **YINM** | **ELON** |
