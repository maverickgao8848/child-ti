# 儿童TI 人格诊断书扩展框架

> 版本：v2.0（诊断书长图版）
> 日期：2026-06-01
> 关联文档：PRD_kidti.md、persona-design.md

---

## 一、问题陈述

MVP v1.0 的结果页仅展示一段「黑色幽默解读」（约100字），用户反馈内容过短、缺乏深度。v2.0 将诊断书扩展为 **「童年人格全景档案」**，目标单人格内容量达到 **800-1200 字**，覆盖人格成分、情境表现、隐藏面、关系谱、成长预言等维度。

---

## 二、理论框架：六模块架构

诊断书由 6 大模块组成，按阅读顺序自上而下排列：

```
┌─────────────────────────────────────────┐
│  模块0 · 人格判词（已有，头部展示）        │  ← 代号+中文名+一句话定义+Slogan
├─────────────────────────────────────────┤
│  模块1 · 核心画像                        │  ← 黑色幽默解读（精炼至1段，100字）
├─────────────────────────────────────────┤
│  模块2 · 人格成分解析                     │  ← 4维度各自如何塑造了这个人格
├─────────────────────────────────────────┤
│  模块3 · 情境剧本                         │  ← 5个核心童年情境的具体表现
├─────────────────────────────────────────┤
│  模块4 · 隐藏档案                         │  ← 外人看不到的内心戏
├─────────────────────────────────────────┤
│  模块5 · 人格关系谱                       │  ← 最合得来/最互相折磨/最看不懂
├─────────────────────────────────────────┤
│  模块6 · 成长预言                         │  ← 长大后的典型路径
└─────────────────────────────────────────┘
```

### 2.1 模块0 · 人格判词（Header）

已有字段，不改动：
- `code`：英文代号（如 BOSS）
- `name`：中文名（如 混沌魔王）
- `definition`：一句话定义
- `slogan`：Slogan

### 2.2 模块1 · 核心画像（Core Portrait）

**定位**：诊断书的"封面故事"，用最具冲击力的1段话建立人格第一印象。

**内容要求**：
- 保留 v1.0 的「黑色幽默解读」风格
- 精炼至 **1 段，80-120 字**
- 用第二人称"你"直接对话
- 必须包含至少1个具体童年场景（而非纯抽象描述）

**示例（BOSS）**：
> 你不是故意的，你只是一出现，秩序就死了。老师看到你的背影就头疼，家长看到你的成绩单就沉默。你是最终Boss，出场自带灾难片BGM。

### 2.3 模块2 · 人格成分解析（Component Breakdown）

**定位**：把人格"拆成零件"，让用户理解自己为什么是这个人格，而非其他23种。

**内容结构**：4个子模块，分别对应4个维度在该人格中的表现。

| 维度 | 子模块标题 | 写作角度 |
|---|---|---|
| NRG | 能量源 · 你的电池怎么工作的 | 解释 BATTERY/REACTOR 在这个人格中的具体表现 |
| RUL | 规则观 · 你眼里的规则是什么 | 解释 SHEEP/WOLF 在这个人格中的具体表现 |
| PRE | 存在感 · 你在人群里的位置 | 解释 BLACKHOLE/SPOTLIGHT 在这个人格中的具体表现 |
| EMO | 情绪天气 · 你的心情预报 | 解释 STORM/LAKE/FOG 在这个人格中的具体表现 |

**写作要求**：
- 每段 **60-100 字**
- 用具体童年行为替代抽象概念（不说"你很内向"，说"课间操你总躲在厕所直到结束"）
- 说明这个维度如何"放大"了其他维度的效果（交互效应）

**示例（BOSS 的 NRG 成分）**：
> 你是 REACTOR（放电型）——不需要充电，越折腾越精神。别人的课间是休息，你的课间是「执行破坏计划」的黄金时间。你的能量不是电池存储式的，而是核裂变式的：一旦启动就停不下来，直到有人把你按回座位。

### 2.4 模块3 · 情境剧本（Scenario Scripts）

**定位**：用5个"经典童年场景"展示这个人格的真实行为模式。

**5个固定情境**：

| 情境 | 场景设定 | 写作焦点 |
|---|---|---|
| **家庭餐桌** | 晚饭时间，父母问了今天在学校怎么样 | 面对权威/亲密关系时的反应模式 |
| **学校课堂** | 数学课上，老师提了一个你不会的问题 | 面对压力/规则时的反应模式 |
| **课间社交** | 下课铃响，同学们三五成群出去活动 | 面对同伴/群体时的反应模式 |
| **独处时刻** | 放学后，一个人待在房间里 | 面对自己/空虚时的反应模式 |
| **突发冲突** | 同桌不小心把你的文具盒撞掉了 | 面对意外/冲突时的反应模式 |

**写作要求**：
- 每个情境 **1 段，80-120 字**
- 用"如果…你会…"的句式，让用户代入
- 不是描述"典型的一天"，而是聚焦**一个瞬间**的具体反应
- 可以轻微夸张，但必须基于真实儿童行为逻辑

**示例（BOSS · 突发冲突）**：
> 同桌撞掉你的文具盒，里面的东西撒了一地。你的第一反应不是生气，而是觉得——机会来了。三秒后，整个小组的课桌都被「意外」波及，而你是唯一一个「刚好」站在旁边、一脸无辜的人。

### 2.5 模块4 · 隐藏档案（Hidden File）

**定位**：揭示这个人格最不想让别人知道的真实内心。

**写作要求**：
- **1 段，80-120 字**
- 揭示与表面行为相反的内心动机
- 使用「表面…其实…」的反差结构
- 要有"刺痛感"——让读者产生"你怎么知道？"的共鸣

**示例（BOSS）**：
> 表面上你享受混乱，其实你只是不知道「正常」是什么感觉。每次搞完破坏，你都会偷偷观察别人的反应——不是因为得意，而是因为你在学习：「刚才那样做，别人是什么表情？这算『成功』了吗？」你不是 chaos 的创造者，你是 chaos 的模仿者。

### 2.6 模块5 · 人格关系谱（Relationship Map）

**定位**：把24种人格看作一个生态系统，说明你的人格在这个系统里的位置。

**内容结构**：3组关系，每组包含「人格代号+中文名+关系理由」。

| 关系类型 | 选择标准 | 示例（BOSS） |
|---|---|---|
| **最佳拍档** | 能互补你的短板，或能跟你一起搞大事的人格 | STUDY（聪明反骨）——他出计划，你出执行 |
| **天生冤家** | 价值观完全对立，看到对方就生理性不适的人格 | WALL（奖状陈列品）——他守规则的样子让你想呕吐 |
| **最看不懂** | 行为逻辑完全在你理解范围之外的人格 | 502ER（502精）——你理解破坏，但不理解「粘着别人不放」是什么意思 |

**写作要求**：
- 每种关系 **1 句核心判断 + 1 句解释**，共约30-50字
- 要有"化学反应"的描述，而非简单标签
- 避免选择同象限人格（如 BOSS 的最佳拍档不要选 TNT 或 CHAOS）

### 2.7 模块6 · 成长预言（Prophecy）

**定位**：给出一个有黑色幽默感的"长大后预言"，作为诊断书的收尾。

**写作要求**：
- **1 段，60-100 字**
- 不是励志鸡汤，而是基于童年行为模式的逻辑推演
- 可以带一点警示意味，但不要太沉重
- 结尾要有"开放式悬念"

**示例（BOSS）**：
> 长大后你大概率会在某个需要「打破常规」的领域闪闪发光——创业、艺术、极限运动，或者重症监护室。前提是你能活到找到自己的轨道。在那之前，你可能会先被几个「常规」碾过去。好消息是：每次被碾，你都会变得更会碾别人。

## 三、内容风格规范

### 3.1 语气基调
- **主体**：第二人称"你"，直接对话
- **距离**：像是一个看穿你的朋友在跟你聊天，不是专家在给你下诊断
- **幽默**：黑色幽默、自嘲、反讽，避免低俗梗
- **温度**：刻薄但有爱，扎心但不说教

### 3.2 禁止事项
- ❌ 心理学专业术语（如"依恋类型"、"回避型人格"）
- ❌ 价值判断（如"你应该改"、"这样不好"）
- ❌ 性别刻板印象
- ❌ 涉及真实儿童虐待/创伤的过度描写
- ❌ 与 v1.0 已有内容（黑色幽默解读）大面积重复

### 3.3 字数控制

| 模块 | 段数 | 每段字数 | 小计 |
|---|---|---|---|
| 核心画像 | 1 | 80-120 | ~100 |
| 人格成分解析 | 4 | 60-100 | ~300 |
| 情境剧本 | 5 | 80-120 | ~500 |
| 隐藏档案 | 1 | 80-120 | ~100 |
| 人格关系谱 | 3 | 30-50 | ~120 |
| 成长预言 | 1 | 60-100 | ~80 |
| **总计** | — | — | **~1200 字** |

## 五、前端展示策略

### 5.1 页面布局

结果页采用**长图滚动**形式，将6个模块以卡片式纵向排列：

```
┌──────────────────────────────┐
│  [人格配图]                   │
│  BOSS                        │
│  混沌魔王                     │
│  全场破坏王，行走的灾难        │
│  "你是最终Boss..."            │
├──────────────────────────────┤
│  📊 你的童年人格维度           │
│  [4条进度条]                  │
├──────────────────────────────┤
│  🧠 人格诊断书                 │
│  ┌────────────────────────┐  │
│  │ 核心画像                │  │
│  ├────────────────────────┤  │
│  │ 人格成分解析（4维度）    │  │
│  ├────────────────────────┤  │
│  │ 情境剧本（5场景）        │  │
│  ├────────────────────────┤  │
│  │ 隐藏档案                │  │
│  ├────────────────────────┤  │
│  │ 人格关系谱              │  │
│  ├────────────────────────┤  │
│  │ 成长预言                │  │
│  └────────────────────────┘  │
├──────────────────────────────┤
│  [分享给朋友] [复制链接]      │
│  [重新测试]                   │
│  [二维码]                     │
└──────────────────────────────┘
```

### 5.2 视觉设计要点

- 每个子模块用**小标题 + 分隔线**区分，保持阅读节奏
- 「人格成分解析」4段之间用轻度缩进或不同左侧色条区分维度
- 「情境剧本」5个场景用小图标前缀区分（🏠🎓👥🌙⚡）
- 「人格关系谱」用卡片式并排展示3组关系（移动端垂直堆叠）
- 整体保持 v1.0 的配色体系，不做大的风格变更

### 5.3 海报适配

分享海报（750×1334）内容有限，**不展示完整诊断书**。海报保持 v1.0 的精简版式：
- 品牌名 + 人格配图 + 代号 + 中文名 + 定义 + Slogan + 二维码

完整诊断书仅在线上结果页展示。

## 六、生成工作流

由于24种人格 × 6模块 = 大量内容生产工作，推荐采用以下流程：

```
1. 将「persona-generation-prompt.md」喂给专门的内容生成 AI
2. AI 按批次输出24种人格的完整 JSON 数据
3. 人工审校：检查风格一致性、避免重复、修正偏差
4. 将审校后的内容写入 personas.js
5. 前端回归测试：验证所有字段正确渲染
```
